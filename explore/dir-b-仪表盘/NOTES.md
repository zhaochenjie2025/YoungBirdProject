# 方向 B — 仪表盘 / 精密仪器

## 核心母题
把「营养数据」当成一台台面式精密仪器的读数：每条记录是一条打孔记录纸带，每日热量是一根在刻度盘上探索的指针，单餐是带铭牌与量程的规格卡。用户看到的不是「猜出来的大数字」，而是「量出来的读数」。

## 三个关键工艺细节
1. **单一比例源推到一切刻度**。`SCALE_MAX=2000 / MINOR=100 / MAJOR=500` 三个常量同时驱动：刻度盘的刻度线角度与长度、红色警戒弧（1800–2000）、周视图柱高及其网格线、实时汇总的游标尺。刻度和网格因此天然严丝合缝，没有一处是手摆的。
2. **记录纸带（punched tape）**。今日记录不是圆角列表，而是带连续齿孔边缘的纸带，行间是撕线虚线；周视图是同一纸带的竖排投影，未记录日是一段被撕掉的空虚纸（斜纹 + 断头红裁口），数据不完整日是琥珀斜纹柱 + 打孔警示点。纸带母题把日/周两个界面统一成同一台仪器。
3. **珐琅面板 + 开槽螺丝 + 压印铭牌**。米白面板用 SVG 湍流噪声做哑光珐琅纹理，四角是带一字槽的螺丝头，面板双层刻线内框、斜切角 `clip-path`；刻盘是真实环形刻度带（annulus），外圈滚花快门钮用 `repeating-conic-gradient` + 径向遮罩做出机加工纹路。红色指针保留「昨日读数」的淡色参考针，让用户看到增减关系。

## 性能取舍
- 零外部依赖：内联 CSS/JS，不引 CDN 字体、不联网；纹理由 `data:` URI 内联 SVG 噪声，单文件 ~63KB。
- 动画只动 `transform`（指针旋转、导航档位滑块、数值滚读）与 `opacity`；不用每帧改 `left`/`width`。
- 周视图柱高用一次性 CSS 过渡；`prefers-reduced-motion` 下全部退化为瞬时。
- 刻度盘、周图、迷你仪表均用程序生成 SVG 路径，静态部分不重算；不做全屏 WebGL。
- 手机优先：基准 390×844，360 宽实测无横向溢出（docW==viewport）。`viewport-fit=cover` + 安全区适配。
