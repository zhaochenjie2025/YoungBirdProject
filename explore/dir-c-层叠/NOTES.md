# 方向 C · 空间纵深 / 层叠卡片

**核心母题**：一餐 = 一叠可以推开、翻起、叠合的实体菜卡；整餐热量是这叠卡片的合力，每加一道就从下方翻上来一张，小票上的数字随叠合实时长出来。

## 三个关键工艺细节
1. **单一阴影推导公式**：所有卡片只从 `--sh-a/b/c` 三条公式取阴影，随 `--dz`（由叠放层号 `--i` 派生）一起加深、加远、加散。层越高离桌越远、投影越深，视觉层级永远一致，不存在各卡各写阴影。
2. **小票纸带是真账单**：热敏小票用 `mask` 做上缘撕齿、`radial-gradient` 打穿孔圆点，热量/蛋白/脂肪/碳水按收据排版，脏了盖「已估算 / N 道待估」橡皮章。加菜时小票数字跳变，与卡片叠合是同一动作的两面。
3. **卡片由物理材质堆成**：每张卡叠纸纤维颗粒、织纹、顶部被上一张卡压出的暗带、左缘类别色条（叠起来成一列菜品配比）、胶带钉角、右缘可推开撕口。深层卡自动收成紧凑表头，数字刚好落在露出条带内不被切。

## 原创细节
叠卡不是静态装饰——**顶卡可以横向甩开（pointer 拖拽 + 回弹），甩过 34% 即碎出画面并从餐里删掉**；份量切换、删卡、加卡都只重绘这一叠，小票数字同步重算。这一处只有「卡片即实体」的方向才成立。

## 性能取舍
- 零库零网络零 WebGL，整文件约 58KB，只用 CSS transform/opacity + 一层 `perspective`。
- 渲染上限 4 层，第 5 道起汇总成「上面还压着 N 道」，避免 DOM 与层数线性膨胀。
- 动效全部走合成器属性；`prefers-reduced-motion` 降到近乎瞬切。
- `?demo=1` 可预置早餐，审阅「今日」有记录态；默认进来是空状态。
