# D 号方向 · 食谱手账 / 编辑排版

## 核心母题
把每一餐当成一本私人饮食刊物的一期。**排版本身就是容器**：大字号数字、竖排书脊、
栏线、页码、日期戳、吊挂序号、引线点、脚注匕首号——没有圆角卡片、没有阴影容器。
纸墨二色（黑墨 `#1c1913` + 朱砂 `#b23a26`），中式宋体报头，拉丁数字用衬线等宽数字。
可切换五屏：今日 / 今日空版面 / 新建一餐 / 单餐结果 / 七天账簿。

## 三个关键工艺细节
1. **刊物期号是真数据**：期号由「记录日期 − 项目起点」逐日算出，书脊竖排
   `NO.22 · 11月23日` 与报头「第 22 期」同源；空版面也有期号，月份印章从日期反推。
2. **中文排版的硬调校**：字号以 1.25 公比做模块化阶梯（13/16/20/25/31/39/49/61），
   正文行高 1.75、注 1.6；全角标点；数字一律 `font-variant-numeric: tabular-nums`，
   大字号再叠 `lining-nums`；日期戳用 SVG `feTurbulence` 做橡皮图章的缺口与歪斜。
3. **数据表与脚注**：单餐结果用真 `<table>`（项目 / 每 100 克 / 本份），栏线 + 点引，
   `†`/`‡` 匕首号对应章末「出处与口径」；番茄炒蛋等含 `kcalRange` 的菜以朱框区间标注，
   缺失值一律显式「暂无数据 / 待估算」，绝不显示 0。

## 性能取舍
- 单文件 64 KB，零外部依赖、零网络请求：纸纹与印章缺口都是内联 `data:image/svg+xml`，
  字体走系统宋体栈（无 CDN）。
- 动画只用 `opacity` / `transform`（页面进场、数字弹跳、印章静态）；抽屉用 `grid-template-rows`
  0fr→1fr 过渡；`prefers-reduced-motion` 全量降级。
- 营养计算复刻 `src/domain/nutrition.ts` 的「按 100 克线性缩放 + 缺失传播为 null」；
  `dayStats` 现算，改删后统计天然一致。实测 DCL 17ms、资源 0 字节。

## 自检
- 360px：无行溢出、无越界、无单字成行；周汇总与账簿在窄屏重排干净。
- 拍照仍是主操作（today / new 页顶部黑色快门条 + 圆孔快门）。
- 本题材独有：报头、等比字号阶梯、竖排书脊、刊物期号、点引账簿、章末脚注——可复用的只有「刊物」这层隐喻。
