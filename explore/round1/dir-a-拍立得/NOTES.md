# 方向 A — 拍立得 / 胶片 / 纸感

## 核心母题
「一餐 = 一张即时成像相纸」：菜名与克数写在相纸下沿留白（chin），热量以胶片日期
压印留在相片角。整套界面是一间暗房——深色的墙、暖橙安全灯（= 拍照动作），
**相纸是唯一发光物**（暖白自发光 halo + halation，四周压暗，形成值域反转）。

## 三个关键工艺细节
1. **相纸即光源 + 实体厚度**（`.print`）：暖白渐变 + 多级 box-shadow；纸芯做了三层
   边（外受光细边 / 纤维本色 / 背光暗边）+ 下沿 1.5px 实体厚度；照片窗口内一道
   halation 暖晕 + 斜向曝光衰减 + 偏色（暗部偏青、高光偏暖）+ 暗角。
2. **显影接触印相条**（`.contact`）：与周视图共用 35mm 齿孔语法，两端是胶片引导舌；
   拍到的菜一格一格浮现（`develop` 只动 opacity/scale），尾部一格真实「未曝光」片基。
3. **车削机械快门 + 背光导航**（`.shutter`/`.tabbar`）：滚花齿边 + 车纹环 + 黄铜光圈
   刻度 + 镜头高光，按下内圈真陷回弹；导航是金属条上的背光刻字窗口，选中项从槽底漏光。

## 性能取舍
零依赖、零网络：图像全为内联 SVG（按菜色给不同机位/暖调/受光），渐变抽单份 sprite
避免 id 冲突；不过滤大图、不做 WebGL、9 个 SVG 不各跑 feTurbulence（颗粒由外层相纸
CSS 噪声统一叠压）。动画只用 transform/opacity，`prefers-reduced-motion` 生效。
单文件约 55 KB（<120 KB）；390/360 无横向溢出、无 console 报错。

## 最具原创性的一处
「显影接触印相条」：新建一餐时快门作绝对焦点，下方相纸留一条胶片显影区，拍到的菜
一格一格浮现——把「拍照录入」本身做成照片正在显影的物理隐喻。
