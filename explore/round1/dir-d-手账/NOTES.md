# D 号方向 · 食谱手账 / 编辑排版

## 核心母题
把每一餐当成一本私人饮食刊物的一期。**排版本身就是容器**：大字号数字、栏线、裁切标、
日期戳、吊挂序号、点引账簿——无圆角卡片、无阴影容器。纸墨二色（黑墨 + 朱砂），中式宋体
报头，数字用衬线等宽数字。五屏可切换。

## 三个关键工艺细节
1. **刊物期号是真数据**：由「记录日期 − 项目起点」逐日算出；报头「第 22 期」、底栏「页22 /
   页16-22 / 附页」同源；顶部 L 形套准角标指向版心、竖排本屏栏目名。空版面与印章日期反推。
2. **中文排版硬调校**：1.25 公比字号阶梯（11 标注级→13/16/20/25/31/39/49/61，无 9/10px）；
   正文行高 1.75、注 1.6；全角标点；CJK 字距一律 ≤0.04em；数字 `tabular-nums`（大字叠
   `lining-nums`）；内容中点全部改全角空格分列，仅留吊挂序号 `01·` 与脚注符号。
3. **印刷材质层**：帘纹纸（横帘线 26px + 纵纸纹 3px + 纤维湍流 + 左侧叠页阴影）；巨号用
   800 重、压印 text-shadow、左切版口；主操作为「订报回执」（顶部齿孔撕线 + 朱色橡皮印章
   「本期主稿」+ 准星圆环）；四档线制（节级 2.5px / 栏级 1px / 行级 .28α / 点引）。

## 字体栈在 Linux / Android 的实际落地
`--serif` 中文优先项已换成 `Noto Serif CJK SC`（不再把 macOS 的 Songti SC 放最前）。CDP 实测本机：
报头中文 → Noto Serif CJK SC（真衬线）、数字 → Liberation Serif、UI → Noto Sans CJK SC。风险：原生
Android 不带衬线 CJK，整体回退 Noto Sans（黑体）——版式不塌、仍可读，但衬线气质丢失；零外链硬约束下无 CDN 字体可补，此为本方向最大跨平台风险。

## 性能取舍
单文件 ~71KB，零外部依赖、零网络请求（纸纹/印章为内联 SVG + CSS 渐变，系统字体栈）。动画只用
`opacity`/`transform`，抽屉 `grid-template-rows` 0fr→1fr，`prefers-reduced-motion` 全量降级
（实测 1e-06s）。营养计算复刻 `src/domain/nutrition.ts`，统计现算故改删一致。

## 经两轮审美质询定案
空版面仅 `#/today-empty` 进入；明细多道默认全折叠；朱砂只留编辑标记，「数据不完整」用斜纹墨条；
今日不铺底色改版口朱竖线；展开用折角箭头、`+` 独占加菜。自检：390/360 无溢出、无报错、P0=0。
