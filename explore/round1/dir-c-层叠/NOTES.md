# 方向 C · 空间纵深 / 层叠卡片

**核心母题**：一餐 = 一叠可以推开、翻起、叠合的实体菜卡；整餐热量是这叠卡的合力，每加一道就从下方翻上来一张，小票上的数字随叠合实时长出来。

## 三个关键工艺细节
1. **卡厚 ∝ 千卡**：每张被压的卡按自身热量露出表头，越靠后按「前面所有卡厚度之和」上抬；卡底做三层硬偏移暗影+受光亮线的侧壁，读作切出来的纸厚（借 React Bits Tilted Card 的挤出做法）。整摞总高 = 整餐热量——母题在几何上成立。
2. **热敏小票是真账单**：撕齿用 `mask` 直接切在纸体上（中段实心 + 上下齿列并集），`drop-shadow` 跟随锯齿轮廓落影（借 Tear Ticket + trevornoah 卷纸明暗）；穿孔为钉在撕线中轴的打穿孔；盖不规则墨迹橡皮章。
3. **今天也是几摞实体卡**：今日按餐次把菜叠成可翻看的卡摞（卡高∝千卡、侧壁厚度、黄铜鸡眼扣、宏量打孔刻度条），未记录的餐次做成文件夹标签卡槽提示「这里还能叠」，合计印在卡摞正下的桌面落款。

## 原创细节
**顶卡可横向甩开删菜（需真有甩速 + 过 40% 阈值），松手飞出后弹出一张可撤销纸条**；份量切换、删卡、加卡都只重绘这一叠、小票同步重算。只有「卡片即实体」的方向才成立。

## 性能取舍
- 零库零网络零 WebGL，整文件约 79KB，只用 CSS transform/opacity + 一层 `perspective`。
- 新建页绘制上限 4 层，更老的菜汇总成卡摞底部的加厚侧边（计数长在卡摞上，非浮字）。
- 动效全走合成器属性；`prefers-reduced-motion` 降到近乎瞬切。
- `?demo=1` 预置早餐看有记录态；默认进空状态。

## 3D 升级裁决（零依赖约束下）
实体卡母题本可用 WebGL 做真实厚度与卷边，但硬约束是零依赖、无 WebGL、≤120KB 单文件。CSS transform + 推导阴影 + 纸材质 + 多层伪元素侧壁已能稳定表达「可推开/叠合」的物理层级，故不升级 3D；代价是没有真实曲面卷边与自遮挡，靠投影层级、侧壁硬影与纸纹弥补。
