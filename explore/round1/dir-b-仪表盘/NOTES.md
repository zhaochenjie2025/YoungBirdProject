# 方向 B — 仪表盘 / 精密仪器

## 核心母题
把「营养数据」当成一台台面式精密仪器的读数：每条记录是一条打孔记录纸带，每日热量是一根在刻度盘上探索的指针，单餐是带铭牌与量程的规格卡。用户看到的不是「猜出来的大数字」，而是「量出来的读数」。

## 三个关键工艺细节
1. **单一比例源推到一切刻度**。`SCALE_MAX=2000 / MINOR=100 / MAJOR=500` 三个常量同时驱动：刻度盘刻度线与长度、红色警戒斜纹带（1800–2000）、周视图共用 y 轴标尺与柱高、实时汇总游标尺。刻度与网格天然严丝合缝，没有一处手摆。
2. **记录纸带（punched tape）是母题主干**。今日记录是奶油纸 + 两侧连续打孔（透出机身黑底）+ 行间齿孔撕线，从面板下沿垂出；周视图是同一纸带的竖排投影——柱是带撕裂毛边顶的纸带条，未记录日是一段空虚纸（斜纹 + 「—」），数据不完整日是琥珀斜纹条 + 柱顶旗杆打孔点。纸色与暗色机身形成对比，把日/周统一成同一台仪器。
3. **下沉刻度槽 + 穹顶玻璃 + 顶板快门**。刻度带做成下沉环槽（外沿内阴影 + 内壁亮唇）；指针用 `feDropShadow` 投真实软影并留高光；罩一层穹顶玻璃（径向高光 + 上肩亮弧 + 边缘暗角）。主操作快门嵌入机身顶板的铣削沉槽，不再是浮空圆钮。

## 性能取舍
- 零外部依赖：内联 CSS/JS，不引 CDN 字体、不联网；纹理由 `data:` URI 内联 SVG 噪声，单文件 ~78KB（≤120KB）。
- 动画只动 `transform`（指针旋转、导航档位滑块、数值滚读）与 `opacity`；不做每帧改 `left`/`width`。
- 周视图柱高用一次性 CSS 过渡；`prefers-reduced-motion` 下指针过渡实测为 0s。
- 刻度盘、周图、迷你仪表均程序生成 SVG 路径，静态部分不重算；不做全屏 WebGL。

## 3D 判定（质询结论）
不需要 WebGL/Three.js。母题是「平面雕刻面板 + 机械读数」，缺的是 2.5D 光影（环槽内阴影、指针投影、玻璃罩扫光、滚花高光），均已用 CSS 渐变 / `drop-shadow` / SVG 滤镜做到；上真 3D 只增负担不增收，且与零依赖约束冲突。

## 两个待决项的质询结论
- **A 全景刻度盘是否压过拍照**：不砍盘，把快门并入仪器顶板（已落地），主操作与主视觉合一，读数面积得以保留。
- **B 撕纸红裁口是否过强**：不过强，是色用错。红色语义已收束——红只留给「警戒/读数」，未记录改纸色空虚纸，撕口不再用红。
