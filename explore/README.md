# 视觉方向探索（不参与构建）

四个方向的产物，均为自包含单页、零外部依赖。

打开 `index.html` 可并排对比：

```bash
cd explore && python3 -m http.server 8799
# 浏览 http://127.0.0.1:8799/
```

| 方向 | 母题 | 文件 |
|---|---|---|
| A 拍立得 | 一餐 = 一张即时成像相纸，整套界面是暗房 | `dir-a-拍立得/` |
| B 仪表盘 | 营养数据是精密仪器的读数 | `dir-b-仪表盘/` |
| C 层叠 | 多道菜在 Z 轴叠合、推挤 | `dir-c-层叠/` |
| D 手账 | 每餐是一本私人饮食刊物的一期 | `dir-d-手账/` |

## 定稿之后

方向选定后，只需替换 `src/styles/global.css` 的令牌（颜色、间距、字号、圆角），
组件结构不用动。若某方向有令牌表达不了的结构性特征（如 B 的纸带、A 的相纸边界、
D 的竖排书脊），再改 `src/styles/app.css` 与对应页面组件的 DOM。
