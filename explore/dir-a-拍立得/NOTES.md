# 方向 A — 拍立得 / 胶片 / 纸感

## 核心母题
「一餐 = 一张即时成像相纸」：菜名与克数用手写体写在相纸下沿留白（chin），热量以
胶片日期压印留在相片角。整套界面是一间暗房——深色的墙、暖橙安全灯（= 拍照动作），
**相纸是唯一发光物**（暖白自发光 halo + halation，四周压暗，形成值域反转）。

## 三个关键工艺细节
1. **相纸即光源**（`.print`）：暖白渐变 + 多级 box-shadow（自发光/接触阴影/纸芯受光
   细边）；照片窗口内一道 halation 暖晕，纸纤维颗粒用 inline SVG 噪声 multiply 叠压，
   显影区四角压印暗角。
2. **显影接触印相条**（`.contact`）：与周视图共用 35mm 齿孔语法；拍到的菜一格一格
   「浮现」（`develop` 只动 opacity/scale），尾部留一格「未曝光」空槽。
3. **车削机械快门**（`.shutter`）：滚花齿边 + 车纹金属环 + 黄铜光圈刻度 + 镜头高光；
   按下内圈真陷再回弹。

## 性能取舍
零依赖、零网络：图像全为内联 SVG（按菜色给不同机位/暖调），渐变抽单份 sprite 避免
id 冲突；不过滤大图、不做 WebGL。动画只用 transform/opacity，`prefers-reduced-motion`
生效。单文件约 53 KB（<120 KB）；390/360 无横向溢出、无 console 报错。

## 最具原创性的一处
「显影接触印相条」：新建一餐时快门作绝对焦点，下方相纸留一条胶片显影区，拍到的菜
一格一格浮现——把「拍照录入」本身做成照片正在显影的物理隐喻。

第 1 轮 3.5/10 打回 → 返工（相纸当光源/厚下沿/快门机械化/建议条改胶带便条/缩略条补未曝光槽/周视图补齿孔帧号边印/导航背光刻字/开关改打孔标签）；第 2 轮 7/10「已脱离模板半成品」，并修正建议条与实际菜品不符。未做（须 WebGL/Blender，超出零依赖 ≤120KB）：① 盘中食物仍扁平矢量，达不到实拍层次（当前最大短板）；② 快门滚花/内筒仍 CSS 平均纹理，缺真车削转折。建议留到位图资产管线时集中处理。
