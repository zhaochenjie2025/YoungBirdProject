# 方向 H · 编辑 / 杂志版式

## 参考与借用（这一轮的重点）
- 借自 **React Bits · Split Text**：每个字一个遮罩槽、字符从下方滑入。落地为大标题逐字升起（今日 / 新建 / 结果 / 周视图四屏首行），换屏重放。
- 借自 **Magic UI · Number Ticker**：每位数字一列、竖向滚筒逐位落位。落地为主热量数字（834 / 355）与换屏重入，纯 transform。
- 借自 **Magic UI · Text Highlighter**：色带自左向右刷出。落地为编辑评注里的钴蓝实心色带（「蛋白质偏少」「碳水占八成供能」），只描那句结论。
- 借自 **React Bits · Halftone Reveal（静态版）**：网点显影。落地为拍照位——网点密度向中心渐隐 + 四角裁切规矩线 + 底部裁切刻度尺，是「图片位」的印刷语言。
- 借自 **React Bits · Rubber Segment → 改造为印刷量规条**：连续轨道 + 内部栏线 + 墨块选中。落地为份量三段选择，不是三个描边按钮。
- 借自 **React Bits · Scroll Reveal**：错峰入场。落地为周视图七根柱、营养三横条、栏线分节的依次显形。
- 借自 **Magic UI · Bento Grid（改造）**：非对称信息格。落地为「用栏线而不是卡片切分」的三餐列表与数据区。
- 另自发做的印刷语义件：换版时钴蓝**套准线**横扫 + 纸色版跟随（不是整页淡入）；黑页沿装订侧一道暗折。
- 标杆参照：Kinfolk / Cereal（超大留白、单栏窄文本）、NYT 数字特稿（字号强对比与图文节奏）、Bloomberg Businessweek（黑页跨页、统计横条、序号栏线）、Pentagram / Order（版面即主角）。

## 核心母题（一句话）
**这张页面就是一份校园饮食周报的版面**——容器是栏线与留白，不是卡片；裁切直角，强调色只有一管钴蓝油墨。

## 三个关键工艺细节
1. **纸是承印物，不是色块**：三层静态肌理（低频纸浆云斑 420px + 高频纤维 180px + 横向长纤维 300px）乘色叠压；巨号热量数字做凸版压印（贴纸油墨压边 + 接触影），放大可看出是压进纸里的。
2. **排版真调过**：字号阶梯 44/26/21/17/15.5/12.5/11.5；正文与导语、注、明细出处用系统衬线（Songti / Noto Serif CJK），标题与数字用重黑，形成「重黑标题 × 衬线正文」编辑对位；数字一律 `tabular-nums`；中文全角标点、断行不留标点。
3. **数据有图版语言**：周视图动态定标（峰值×1.08 取整到 300 的倍数，故柱占满 82% 高度）、实墨/斜纹/虚线框三种编码与图例一一对应、未记录日留虚线基线绝不画零高柱；单餐区间条可拖端点直接改克数并重算合计数与明细表；营养用通栏统计横条 + 100% 终线端点。

## 性能取舍
单文件 67 KB（预算 120 KB），零外部依赖、零网络请求（纹理全为内联 `data:image/svg+xml`，系统字体栈）。
动画只动 transform / opacity / width；`prefers-reduced-motion` 全量降级（含套准线转场、逐字、滚筒、柱高）。
营养计算复刻 `src/domain/nutrition.ts` 规则（每 100 克 × 克数 ÷ 100，区间等比缩放，缺失传播 `null`），缺失值显示「暂无数据 / 待记录」不以 0 冒充。
