# 方向 F · 玻璃拟态 / 柔和界面（高端光感版）

## 参考与借用（这一轮的重点）
- 借自 **React Bits · Fluid Glass / Glass Surface** —— 落地方式：`.glass` 体芯近乎透明（填充≤0.14）+ `backdrop-filter: blur(11px) saturate(240%)` 真采样背景彩色光，厚度只靠四条边（顶亮斜面/底暗玻璃壁/左右薄壁/青-品红色散边环），不是白片。
- 借自 **Magic UI · Progressive Blur** —— 底部坞身后三级叠加模糊（3/12/22px，各自 mask 渐隐），内容真能滚到坞后。
- 借自 **Magic UI · Border Beam** —— 保存按钮与镜头外圈绕行的光点。
- 借自 **Magic UI · Magic Card** —— 菜品瓷片随指针/手指移动的露光斑。
- 借自 **Glare Hover / React Bits · Specular Button** —— 镜头按下镜面扫光 + 快门白闪；减号钮改内凹玻璃碟。
- 借自 **Magic UI · Slosh Gauge（取液面弧光思路）** —— 承光镜底部光池的弯月液面弧。
- 现实标杆：**iOS 26 Liquid Glass**（厚度/边缘高光/折射）、**visionOS** 空间多层材质、**Vercel Fluid Glass**。

## 核心母题（一句话）
「每餐是一层承光的玻璃，镜头（玻璃）是把光聚进来的入口」：拍照=光穿过镜头，每记一餐=多一层截住光的玻璃（承光镜心逐片叠玻璃圆片，层数=餐数）；全天热量=玻璃里困住的光（进度弧+色温冷→暖+底部光池），周视图=七根液光玻璃柱。

## 三个关键工艺细节
1. **玻璃蚀刻凹槽**：菜品清单/算式/营养格/分段器一律是内凹玻璃槽——顶暗底亮的内阴影 + 菜名凹字压印 + 竖线分隔，取代白色圆角胶囊标签。
2. **厚度靠边不靠芯**：顶 2.5px 亮斜面、底 6px 深色玻璃壁 + 反光唇、左右薄壁 + 2px 青-品红色散边环；体芯近透明让背景彩色透上来（实测卡内能读到背景暖光斜率≈0.3，此前≈0）。
3. **液光玻璃柱 + 承光镜**：周柱定高玻璃筒（左缘竖反光条/右缘回光/内壁厚度暗边）内升带内核亮带、弯月液面、底部 caustic 的琥珀液光，不完整态用断开双层液；承光镜为透明玻璃盘，暖光沉在盘底、顶部冷玻璃、液面加弯月弧。

## 性能取舍
零依赖零网络（内联 SVG 噪声/图标，无 CDN 字体；数字用系统 SF Pro Display）。`backdrop-filter` 集中在 `.glass`（11px）与 `.heavy`（镜头/结果 hero/坞/sheet，24px），周柱液体用渐变无 backdrop；动画仅 transform/opacity，`prefers-reduced-motion` 生效。单文件 82.8 KB（<120 KB）。

## 质询迭代（3 轮 haiku 盲审，均要求先加载 creative-frontend 技能）
- **第 1 轮 5.5/10**：判「廉价 2020 glassmorphism」、主镜假刻度、周柱像体温计、数字三重复。
- **第 2 轮 5.5/10**：主镜无「层」、iris 像风扇、周柱液光不发光、isToday 功能 bug。
- **第 3 轮 6.0→6.5/10**：点睛——「伪透光」：卡内 warm≈0，白胶囊只是迁移到 toast/算式/营养格/减号。返工：`.glass` 体芯近透明 + 玻璃高光只覆左上 45%（实测卡内能读背景暖光）、盘体 backdrop 采样页底色光（修 ring-mid 遮满中心的盖子 bug）、toast/算式/dock/减号/btn 全改薄玻璃或内凹槽、营养格加三色液光条、减号改内凹碟、盘底加弯月液面。

## 玻璃拟态在「零依赖 + 盲色背景 + 390 宽」三约束下的诚实上限
- **能到**：造型上高度可信的玻璃——厚度、倒角、色散边、液光、折射采样背景色，一套统一材质语言在四屏成立；周柱、镜头、承光镜已接近工作室级。
- **到不了**：① **真透镜折射**（背景在玻璃边被压缩/倒像/位移）——需 `feDisplacementMap`+法线图或 WebGL 透射材质，超出零依赖单文件预算；当前是 backdrop 模糊+饱和的"磨砂透光"近似，不是几何折射；② 承光镜盘心因位于页顶浅色区，采样到的底本就是浅色，无法像深色背景那样"透出彩光"，这是背景决定的物理上限；③ 真 3D iris 叶片（Three.js 环面+透射）同样超预算。**结论：这是一个"高保真 CSS 玻璃"，不是"物理正确玻璃"，继续硬调只能逼近不能到达。**
