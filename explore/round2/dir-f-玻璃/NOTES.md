# 方向 F · 玻璃拟态 / 柔和界面（高端光感版）

## 参考与借用（这一轮的重点）
- 借自 **React Bits · Fluid Glass / Glass Surface** —— 落地方式：`.glass` 背板 `backdrop-filter` 真折射背景彩色光（saturate 210%）+ `::after` 青/品红薄膜色散边环 + 上沿受光/下沿增厚的斜面倒角，让每张卡片像 3–4mm 磨边玻璃而不是半透明白块。
- 借自 **Magic UI · Progressive Blur** —— 落地方式：底部坞身后三级叠加模糊（3/12/22px，各自 mask 渐隐），内容真能滚到坞后，而不是一块浮起来的灰袋。
- 借自 **Magic UI · Border Beam** —— 落地方式：保存按钮 `::before` conic 光点沿边绕行；镜头外圈 `.orbit` 光点绕镜筒流动（母题「光在绕镜头流动」的动态签名）。
- 借自 **Magic UI · Magic Card** —— 落地方式：菜品玻璃瓷片 `.spot` 随指针/手指（pointermove+pointerdown）移动的露光斑。
- 借自 **Magic UI · Glare Hover / React Bits · Specular Button** —— 落地方式：镜头按下时镜面扫光 `.sweep` + 快门白闪；保存按钮按下一次性扫光。
- 现实标杆：**iOS 26 Liquid Glass**（厚度/边缘高光/折射）、**visionOS** 空间多层材质、**Vercel Fluid Glass**。

## 核心母题（一句话）
「每餐是一层承光的玻璃，镜头（玻璃）是把光聚进来的入口」：拍照=光穿过镜头，每记一餐=多一层截住光的玻璃（承光镜心逐片叠玻璃圆片，层数=餐数）；全天热量=玻璃里困住的光的亮度（进度弧 + 色温冷→暖），周视图=七根液光玻璃柱。

## 三个关键工艺细节
1. **承光镜头 = 母题账本**：外缘 conic 进度弧（12 点起顺时针、0→300°）随热量生长，弧头一颗光点；4 道刻痕锚定 500/1000/1500/2000 千卡里程碑；镜心按餐数叠 1–5 片带上下沿厚度的玻璃圆片（可数），内嵌光晕色温随热量由冷青转暖琥珀。
2. **液光玻璃柱**（周视图）：定高玻璃筒（左缘竖镜面反光条 + 右缘回光 + 内壁厚度暗边）内升一段带内核亮带、弯月液面、底部 caustic 的琥珀液光，柱高∝热量；不完整态画成明显断开的两层液 + 虚线桥（语义化，不靠颜色）；今天柱青环+底光座+「今天」标签三重定位。
3. **玻璃镜头**：多层同心折射环 + 镀膜青/品红色散细环 + 弧形窗影高光 + 12 片金属叶片（径向窄亮宽暗渐变 + 片间机械缝）+ 深色玻璃通光孔（孔内一点偏心近轴暖反光），按下内环收缩对焦 + 镜面扫光 + 快门白闪。

## 性能取舍
零依赖零网络（内联 SVG 噪声/图标，无 CDN 字体；数字用系统 SF Pro Display，非等宽小票腔）。`backdrop-filter` 集中在 `.glass` 基础层（9px）与少数 `.heavy`（镜头/结果 hero/坞/sheet，24px），玻璃柱液体用渐变无 backdrop 控 GPU；动画仅 transform/opacity，`prefers-reduced-motion` 生效。单文件 75.6 KB（<120 KB）。
