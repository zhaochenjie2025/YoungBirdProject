# 方向 J · 日系极简 / 侘寂

## 参考与借用（这一轮的重点）
- 借自 React Bits `Masked Heading` / `Split Text` —— 落地：页标题 `overflow:hidden` 遮罩逐字从 115% 升入，46ms 错峰、0.86s 缓出；内容块 `translateY(9px)` 柔和入场。
- 借自 React Bits `Curved Loop` —— 落地：今日主视觉是一把半圆弧尺，2400 千卡铺满半圆、每 20 一根细刻、每 600 长刻带数字；1800–2200 参考区间**嵌进梳齿节奏**（一段加粗刻度 + 内侧细弧），不是贴在外圈的胶带。指针是锥形实体（根宽 3.4、尖宽 0.7 + 配重圆头），已用量弧起笔 1.1px、收笔随占比加粗到 2px，像一笔墨。
- 借自 Magic UI `Dotted Map` —— 落地：周视图 7 列 × 3 点（早/午/晚），实心=已记录、34% 半透=含估算、空心=未记录（透明度与图例严格同值）；今天一道朱线只贯穿三点，止于点阵下界，不穿数字。
- 借自 Magic UI `Number Ticker` —— 落地：每位数字一列 0–9 竖向位移，48ms/位错峰；首渲染直接定位，只在换份量/切屏时滚动。
- 借自 Magic UI `Progressive Blur` —— 落地：坞上沿两层递增模糊（1.5px / 4px）各自 mask 渐隐。
- 借自 React Bits `Hold Button` / `Slide Commit`（换皮成「按印」）—— 落地：保存按钮 = 一块裁切印面，四角 crop mark，按下整块吃墨。
- 现实标杆：無印良品包装分级（一条朱红、其余纸与墨）；原研哉《白》（白是有层次的）；《&Premium》松字距与注釈栏。

## 核心母题（一句话）
**一页厨房量尺的记账纸**：弧尺量出今日份量，餐次像账本竖排的墨批，拍照是唯一一枚朱印。

## 三个关键工艺细节
1. **留白是算出来的**：尺 = 屏宽/3 = 130，寸 = 13，間 = 26（二寸）；左右边距恒 26，纵向走 13 的倍数；字阶 1.26 倍七级（11/13/15.5/19.5/24.5/31/44）。360 宽降为 120/12/24，布局不重排。
2. **同族刻度语言贯穿三屏**：今日主弧（2400 尺）、结果页区间尺（这道菜区间 ±8% 余量）、周视图收口尺（0–7200 五日合计）都是「细刻梳 + 实段 + 端挡 + 朱针」的同一套语法，只是尺度不同。数值全部运行时由米字表算出。
3. **朱印是刻的**：印面外缘四边不齐、左下起笔刀尾、`feTurbulence` 走 `feComposite in` 做印泥浓淡，内圈一道不闭合刻线；印心是「取景框四角 + 一碗饭」的合成符号（拍照 × 吃），不是通用相机图标。全站唯一实色，只出现在主操作与「此刻」。

## 性能取舍
单文件 57 KB（预算 120 KB）；零依赖、零网络、零位图。纸纤维为 120×120 `feTurbulence` data-URI，`multiply` 4.5% 固定铺顶；弧尺为纯内联 SVG（约 130 根线）。动画只用 transform/opacity；`prefers-reduced-motion` 下揭示与滚动归零（实测 opacity=1、数值照常算出）。390 / 360 / 320 三档四屏均无横向溢出，console 零报错。

## 字体实测（本轮必答）
- 栈：`--f-serif:"Noto Serif CJK SC","Source Han Serif SC","Songti SC","STSong","Hiragino Mincho ProN","Noto Serif CJK JP",serif`；`--f-sans:-apple-system,"PingFang SC","Hiragino Sans GB","Noto Sans CJK SC",…`。
- CDP `CSS.getPlatformFontsForNode` 实测：`.mk-c`（竖排餐次字）→ **Noto Serif CJK SC / NotoSerifCJKsc-Regular**；`.hd h1`、正文、数字 → **Noto Sans CJK SC**。canvas 探针：同一串拉丁字符衬线栈 389.88px vs 无衬线 358.04px，证明确实换字而非静默回退。
- Android 最坏：无 Noto Serif CJK / 宋体 → 落 `serif` → 通常 Roboto Serif 或缺字回退 Noto Sans CJK SC，**仅竖排餐次单字会静默变黑体**。故衬线只用于单字与短标签（约 6 处），读数、正文、按钮全部无衬线，退化只损「墨味」不损可读性。
