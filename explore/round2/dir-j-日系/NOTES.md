# 方向 J · 日系极简 / 侘寂

## 参考与借用（这一轮的重点）
- 借自 React Bits `Masked Heading` / `Split Text` —— 落地：页标题 `overflow:hidden` 遮罩逐字升入，46ms 错峰、0.86s 缓出；内容块 `translateY(9px)` 柔和入场。
- 借自 React Bits `Curved Loop` —— 落地：今日主视觉半圆弧尺（2400 铺满半圆、每 20 一细刻、每 600 长刻带数字）；1800–2200 参考区间**嵌进梳齿**（两端 sin taper）。指针为锥形实体（根 3.4 / 尖 0.7 + 配重头 + 落影），已用量弧起笔 1.1px、收笔随占比加粗到 2px。
- 借自 Magic UI `Number Ticker` —— 每位数字一列 0–9 竖向位移，48ms/位错峰；首渲染直接定位。
- 借自 Magic UI `Progressive Blur` —— 坞上沿两层递增模糊（1.5 / 4px）各自 mask 渐隐。
- **周视图**借自苹果「屏幕使用时间」周柱的信息结构：左 y 轴刻度 + 极淡网格 + 按成分堆叠 + 平均虚线带标注 + 未记录日占位 + 柱顶标极值。HeroUI 只有通用 BarChart/ProgressCircle，无可照搬皮，故只借结构不借样式。
- 现实标杆：無印良品（一条朱红、其余纸与墨）；原研哉《白》；《&Premium》松字距与注釈栏；日式便当盒的分格秩序。

## 核心母题（一句话）
**一页厨房量尺的记账纸**：弧尺量出今日份量，餐次像账本墨批，拍照是唯一一枚朱印；一周是一张灰阶的七日柱。

## Sou39O 视觉收敛（黑白 / 直角 / 统一字）
- **只用黑白灰**；朱红 = 唯一强调色，且只作「今天 / 此刻」语义（今日弧尺针、底部拍照印、主操作筷尖），营养分色**一律不用色相**。
- **营养成分改用灰阶深浅**：蛋白 #231F1C（对纸 17:1）／脂肪 #5C564F（6.4:1）／碳水 #8E887E（3.1:1，压过 3:1 可读底线）；三段感知明度 L*≈14/37/58，台阶均匀，色弱/黑白打印下仍可分辨。
- **直角**：全站圆角收到 0–2px（原 3px 柱顶、50% 圆点已移除）。
- **统一字体**：删掉全部衬线栈（`--f-serif` 已移除），全站单一无衬线；竖排餐次仍 `writing-mode` 但字面统一。
- **说明极简**：脚注压到「日均不计今天 · ≈ 表示缺数据 · 虚线空框＝未记录 · 灰阶＝成分，柱高＝热量」。

## 三个关键工艺细节
1. **留白算出来**：尺 = 屏宽/3 = 130，寸 = 13，間 = 26；边距恒 26，纵向走 13 倍；字阶 1.26 七级。360 宽降 120/12/24，布局不重排。
2. **同族刻度语言贯穿**：今日主弧、份量三档横刻（墨色游标）、结果页区间尺、周视图 y 轴刻齿（每刻度一道短齿，读作立在纸边的量尺）都是「细刻 + 实段 + 刻齿」一套语法。数值全运行时由菜品库算出。
3. **朱印是刻的**：印面四边不齐、起笔刀尾、`feTurbulence` 走 `feComposite in` 做印泥浓淡，内圈不闭合刻线；印心是「取景框四角 + 一碗饭」合成符号。全站唯一实色。

## 性能取舍
单文件 65 KB（预算 120 KB）；零依赖、零网络、零位图。纸纤维 120×120 `feTurbulence` data-URI，`multiply` 4.5% 铺顶；弧尺、周柱、刻齿均为内联 SVG/DOM。动画只用 transform/opacity；`prefers-reduced-motion` 下揭示与滚动归零（实测柱照常显示、数值照算）。390/360/320 四屏无横向溢出、console 零报错；390/360 单屏不滚。

## 周视图可读性验证（不只是"改了"）
- **五问机器断言**：顶部大数=周总量（5,958）；柱高对 1,459/1,018 极值排序正确（highest/lowest 标值）；平均虚线存在且标签「日均 1,192」=已记 5 天均值；三段段高之和每根柱都精确等于柱总高（segDelta 全 0）；19 日为虚线空心格、21 日柱顶 ≈。
- **数值自洽**：361+509=870（今日），5 天柱高之和 ≈ 5,958，÷5 ≈ 1,192。
- **对比度实测**：碳水段对纸 3.1:1（质询初版仅 1.92:1，未达 3:1 已修）。
- **窄屏**：320/360 无溢出、图例与刻齿可读（截图 `wk2-320/360`）。
- **aria**：`.wk-plot` 带整图可读摘要，读屏与质询代理可机器读。
