# 方向 I · 新粗野主义（食堂台账 / 凸版印刷）

## 参考与借用（这一轮的重点）
- 借自 **React Bits `Sling Button`** —— 落地：拍照快门按住往右拉，拉满 46% 宽度才触发；未满松手回弹不发；拖动时六叶光圈转 42° 收拢、底部 5px 行程条同步。松手触发时光圈再收 60° + 白闪。
- 借自 **React Bits `Slide Commit`** —— 落地：保存键是一条 58px 硬槽；滑块拖过 82% 才落账，未过阈值整条回弹到 0；落账后盖下印章并在落点炸火花。
- 借自 **React Bits `Rubber Segment`** —— 落地：份量三档按下先 inset 墨压、再 `scaleX(.9) scaleY(1.08)` 回弹；选中档反色 + 底部黄条。
- 借自 **React Bits `Tear Ticket`** —— 落地：结果页是一张硬纸票据，上沿一排齿孔（径向渐变抠孔）、下沿一圈三角撕边；明细行以 `grid-template-rows 0fr→1fr` 沿折线摊开。
- 借自 **React Bits `Sticker Peel`** —— 落地：周视图「数据不完整」那列右上角一张剪纸角标，点击揭开（rotate −26° 飞走），露出条内「含 N 道待估」。
- 借自 **React Bits `Click Spark`** —— 落地：落账瞬间在滑块终点炸 9 颗方块火花（canvas，三原色轮转，重力下坠）。
- 借自 **Magic UI `Dither Field` / React Bits `Halftone Reveal`** —— 落地：结果页主横幅右下角渐显半调网点，读作印刷网屏。
- 标杆：**Gumroad 2021 改版**（3px 墨线 + 实心偏移影 + 原色块）、**Neobrutalism.dev**（厚边 + 无模糊影）、**Figma brutalism UI kit**（高对比、字号跳档）；母题正当性另取**丝网印刷两版套印**（第二遍油墨更深更暖、与纸块间留 1.5px 对版缝）。

## 核心母题（一句话）
食堂台账直接印在硬纸板上：先铺横向纸纤维，再压墨线（带渗边），最后套印一遍下移 6px、更深的第二遍油墨；按下去 = 纸块沉进自己的墨印里。

## 三个关键工艺细节
1. **统一的压印物理**：`.btn` 按下 `translate(6px,6px)` 且阴影→0（纸块沉进墨印）；dock 按下 `translateY(2px)` + inset 墨压；seg/pick/drop 各自下沉 1–2px。第二遍油墨用 `--ink-deep`，与纸块之间留 1.5px 纸色缝，读作对版差而非普通投影。
2. **今日 = 一张真台账**：印好的列头（№ / 今日菜目 / 份量 / 千卡）、贯穿全屏的栏线、行号 01–06、餐次节头用中文数字一/二/三、合计行用会计双线。剪影层面不可替换。
3. **纸张与墨都是真的**：横向长纤维 `feTurbulence(baseFrequency .014 .5)` + 细颗粒双叠 multiply；墨线边框套 `feDisplacementMap scale 1.6` 渗边副本；印章为透明底 + feTurbulence alpha mask 造缺墨斑、零偏移影。

## 性能取舍
零依赖零网络：图标内联 SVG，纸纤维与网点全为 data-URI SVG，favicon 内联（无 404）。动画只用 transform/opacity；`prefers-reduced-motion` 下过渡归零并禁用火花。单文件 73 KB（<120 KB）。390/360 宽均无横向溢出，console 零报错。
