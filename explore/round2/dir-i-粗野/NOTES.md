# 方向 I · 新粗野主义（食堂台账）

## 参考与借用（这一轮的重点）
- 借自 **React Bits `Sling Button`** —— 落地方式：拍照快门按下时向指针方向偏移（上限 16px，带阻尼），松手用 `cubic-bezier(.2,1.6,.4,1)` 弹回原位；位移期间硬阴影同步收缩一档，读作"拉弓"。
- 借自 **React Bits `Slide Commit`** —— 落地方式：保存键是一条 58px 高的硬槽，滑块拖过 82% 才落账；未过阈值整条回弹到 0，越过则整条填绿并盖下「已记账」印章。
- 借自 **React Bits `Rubber Segment`** —— 落地方式：份量三档按下时 `scaleX(.9) scaleY(1.06)` 再回弹，选中档以反色 + 底部黄条标记，不靠阴影。
- 借自 **React Bits `Tear Ticket`** —— 落地方式：单餐结果是一张硬纸票据，上沿一排齿孔（径向渐变抠孔），下沿一圈三角撕边（`clip-path`），每行明细点击后以 `grid-template-rows 0fr→1fr` 沿折线摊开。
- 借自 **React Bits `Sticker Peel`** —— 落地方式：周视图「数据不完整」那天右上角贴一张红色角标，点击揭开（rotate+translate 飞走），露出条内说明「含 N 道待估算菜」。
- 借自 **React Bits `Click Spark`** —— 落地方式：落账瞬间在滑块终点炸出 9 颗方块火花（canvas，3 原色轮转，重力下坠）。
- 标杆：**Gumroad 2021 改版**（3px 墨线 + 6px 实心硬阴影 + 原色块）、**Neobrutalism.dev** 组件规范（厚边框 + 无模糊偏移阴影）、**Figma brutalism UI kit**（高对比、字号跳档）。
- 本方向把硬阴影解释为"丝网印刷的第二遍油墨套印"：全局统一右下 45°、无模糊、无扩散，因此它是母题的一部分而不是装饰。

## 核心母题（一句话）
食堂台账被直接印在硬纸板上：先铺纸，再压 3px 墨线，再套印 6px 实心第二遍油墨；按下去 = 纸块沉进油墨里，阴影塌成 0。

## 三个关键工艺细节
1. **压印反馈是全局唯一的物理语法**：所有可点物（按钮、餐次卡、快门、滑块）按下都执行 `translate(6px,6px)` 且 `box-shadow→0`，释放再弹回；这一条让"粗"读作"实"，而不是"糊"。
2. **四种容器各有物理出处**：主卡=硬纸板（3px 边+6px 影）、餐次=墨底抬头条+纸身明细、结果=齿孔票据（上下沿不同撕法）、周视图=堆叠硬卡（缺日改成斜线空纸格，不画 0 长度条）。
3. **数字是机械计数滚筒**：每位一列 0–9，切换份量时按位滚动（只动 transform），并保留等宽数字防止跳动。

## 性能取舍
零依赖零网络：图标全为内联 SVG，纸纤维用 140×140 `feTurbulence` data-URI 一次生成、`multiply` 低透明度叠压，favicon 为内联 SVG data-URI（无 404）。动画只用 transform/opacity；`prefers-reduced-motion` 下过渡归零且禁用火花。单文件 62 KB（<120 KB）。
