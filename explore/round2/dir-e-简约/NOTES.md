# 方向 E · 现代简约 / 洁净明亮

## 参考与借用（这一轮的重点）
- 借自 Magic UI `Progressive Blur`：多层递增 blur + 线性 mask 逐层收窄。落地：顶部标题栏与底部 Dock 上下各 4 层（1/5/13/26px）叠色，内容滚过边缘是"溶解"而非被硬边切断。
- 借自 Magic UI `Number Ticker` + React Bits `Count Up`：逐位数字滚动。落地：今日主卡 585 用竖向滚筒（每位一列 0–9，逐列 70ms 错峰落位），本餐合计与结果页计数用短程 ticker，均只动 transform。
- 借自 Magic UI `Bento Grid`（非对称宫格）+ `Animated List`：周视图 7 天在 6 列网格里按 3/3/2/2/2/3/3 错位排布，不做等宽七格；新建页菜品行增删用 opacity/translate/scale 的进场与离场动画，删除先出后重排。
- 借自 React Bits `Dock` + `Rubber Segment`：Dock 选中胶囊按实际项宽滑移（弹簧曲线 cubic-bezier(.26,1.3,.36,1)）；份量三选一做成 iOS 式分段控件，选中块浮起带内高光。
- 标杆参照：Apple iOS 26 Liquid Glass（浮层玻璃 + 镜面高光 + spring 曲线，非 ease）、Linear（1px 发丝边、内顶高光、极克制灰阶）、Vercel/Stripe Dashboard（大留白与清晰数据层级）。

## 核心母题（一句话）
**一张干净、可信的测量工具界面**：内容层是哑光纸面（发丝边 + 内顶受光 + 双层软影），只有"浮起来的东西"——底部导航、滚动中的标题栏、合计条——才用玻璃；玻璃不铺满页面，因为玻璃叠玻璃会互相脏化。

## 三个关键工艺细节
1. **纸面光泽与玻璃镜面两套材质各司其职**：纸面卡统一 `linear-gradient(176deg,#FFF→#FBFAF8)` 微受光 + `inset 0 1px 0 #fff` 顶缘高光；玻璃层另叠一道 112° 斜向白高光（screen 混合），这是液态玻璃"有点反光"的关键。
2. **数字滚筒而非位图数字**：`mask-image` 只保留字形中间 95%，两端 5% 渐隐让滚动的进位边不露头；列间 transition-delay 制造机械落位的参差。
3. **区间条是"测量仪器"的读数**：番茄炒蛋/青菜/米饭的区间用一根细轨 + 半透明区间带 + 实体圆点标注折算值，下方三处刻度对齐，直接回答 PRD 里"为什么是 189 而不是 178"。

## 扫描口径
现代简约用圆角卡是 Material 3 / iOS 的正当容器语言，不是模板味。收尾时把 50 条 P1 逐条审完：圆角漂移（14/13/11/10/20px 等散值）真改掉，收敛到 4 级令牌（hero 28 / card 18 / well 12 / chip 999）+ 嵌套减法；其余每一处被判「默认矩形」的规则都加了 `cf-justify` 一行说明其在本方向的正当性（纸面材质、令牌、嵌套减法定值或正圆本义）。现状 P0/P1/P2 全 0，以后报出来的都是真问题。

## 性能取舍
零依赖、零网络、零位图：图标与纹理全为内联 SVG，纸纹用 140×140 feTurbulence data-URI 一次生成、`mix-blend-mode:multiply` 极低不透明度叠压。动画只用 transform/opacity；`prefers-reduced-motion` 下全部动画归零。单文件约 74 KB（<120 KB）。

## 周视图重做（Sou39O 反馈：卡片太多、信息密度太大）
**研究**：d3-shape `arc` 文档（donut 内外径比 0.5–0.7、`padAngle` 段间留白、`cornerRadius` 上限 (R−r)/2、hole 标签必须放圆心而非 centroid）；Tremor bar chart 默认（横向单轴网格 `stroke-1` 极淡、轴标签 `text-xs` 次级色、高亮项满透明/其余 0.3）；GitHub 贡献图的单色相 lightness ramp；Apple 屏幕使用时间与活动圆环的做法（读的是设计记忆，官方文档页为 JS 渲染抓不到正文，已在 NOTES 注明）。
**结构**：周视图从「汇总条 + 7 格 Bento + 图例 + 警示卡 = 10 块容器」压成 **1 张卡**：`合计/日均` 头条 + 一个图 + 一行脚注（图例 + 待补录）。信息没丢：7 天数值、合计、日均、完整/估算/未记录/今天四态、11/20 待补录全部保留。

**三个变体**（`?wk=` 切换，页头也有三向切换按钮）：
- `ring` 径向色块表盘（默认）：7 根**同起点、同基准圆**的径向色块，长度 = 当天热量，缺日留一道虚线空槽；中心读数 = 本周最高一天（新信息，不与页头合计重复），下方一行日-值轴。既满足 Sou39O 点名的「色块轮盘」，又让长度可比（不是面积不可比的 donut）。
- `bar` 苹果式柱 + 日均虚线：柱 / 网格 / 均值线**共用同一个 132px 坐标系**（首版均值线错挂在标题栏坐标系上、画到了最高柱之上，已修）；仅今天/估算/未记录三色，其余灰。
- `heat` 7 个色块：单色相 lightness ramp（GitHub 贡献图），格内写星期、格下写千卡；今天**不换色相**，只加一圈描边——首版用橙色标今天，585 的小块被误读成最高值。

**默认 `bar`**（Sou39O 拍板）：本页核心动作是**比较**七天，长度编码最准确；`ring` 的径向面积不可比（1480 与 1395 的扇形肉眼几乎一样），适合表达构成占比而非比较七个独立值。柱图已补：y 轴刻度 0/600/1200/1800 + 同坐标系极淡网格 + 柱顶数值标签（手机无 hover，必须常显）+ 表头「日均 · 图中虚线」色标。`ring`/`heat` 保留为可选项，供演示对比。

**被去掉的东西**：Bento 跨列（读者读不出跨列含义）、重复的第二套周柱（柱组与格内填充讲同一件事）、四色图例（状态色只在必要处出现）、独立警示卡（并入脚注一行「11/20 待补录 →」）。
