# 使用效率测试方案

对应 PRD 第四章「使用效率」指标：邀请不少于 15 名学生完成同一项测试任务，
任务完成率目标 ≥ 90%，成功任务从新建到保存的中位用时目标 ≤ 60 秒。

## 测试任务

记录一份含三道菜的餐食，其中**至少一道通过拍照添加、至少一道通过搜索添加**。

## 计时口径

- **起点**：用户点击「记录这一餐」（进入新建页的那一刻）。
- **终点**：用户点击「保存这一餐」并看到明细页。
- 中途失败、重拍、返回重来都算在用时里；没完成的记为失败。

## 执行方式

每个受试者用同一台或同型号手机、同一个浏览器、同一套菜品库。
测试员只念下面的引导语，不提示操作步骤：

> 你现在在食堂吃完了一餐，桌上有三道菜。用这个网页把它们记下来，
> 其中至少一道用拍照，至少一道用搜索。准备好就开始。

## 汇总

```bash
python3 tools/eval-usage.py usage.csv
```

脚本会算：完成率、成功任务的中位用时、是否达标，并列出未完成的原因。
样本不足 15 人时会提示。

## 注意

- 中位数只统计**成功任务**，未完成的进入完成率分母、不进用时统计。
- 受试者应当是第一次见这个界面的人，不要用已经参与过开发的成员。
- 拍照那一步需要 API key。测试前在设置里配好，避免受试者卡在配置环节。
