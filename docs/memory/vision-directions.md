## A 方向要点

母题「一餐 = 一张即时成像相纸」：菜名与克数手写在相纸下沿留白，热量用橡皮图章盖在角落，
整套界面是暗房（深色墙 + 暖橙安全灯 = 拍照动作），相纸是唯一发光物。
三个工艺细节：相纸三件套比例 + 纸纤维颗粒、抽帧式显影动画、35mm 胶片条周视图。
原创点：新建一餐时菜一格一格「显影」浮现，把拍照录入本身做成显影隐喻。

## B/C/D 要点与风险

**B 仪表盘**：单一比例源（量程 2000/小格 100/大格 500）同时驱动刻度盘、警戒弧、周柱与游标尺；
记录纸带母题把日/周统一成同一台仪器。风险：仪器语汇信息密度高，可能压过「拍照」主操作；
全景刻度盘占首屏约 40% 高度。待决：是否改半圆小表盘。

**C 层叠**：所有卡片阴影由同一组 `--sh-a/b/c` 公式随层号派生；小票纸带是真账单；
顶卡可横向甩出删除（甩过 34% 即碎出画面）。风险：推开交互在窄屏上可能误触。

**D 手账**：刊物期号是真数据（记录日期 − 项目起点）；字号 1.25 公比阶梯；真 `<table>` 配匕首脚注。
风险：纯排版依赖衬线中文字体，设备缺字会掉气质；信息密度高、翻阅成本大。

**A 的风险**：手写体依赖楷体回退，缺字安卓机上质感会剩相纸形状撑着。

**四方向共同风险**：都依赖系统字体栈兑现气质，若要上生产可能需子集化内嵌字体，
这会突破「零外部依赖」与体积预算，需要 Sou39O 权衡。
