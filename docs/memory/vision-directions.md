## A 方向要点

母题「一餐 = 一张即时成像相纸」：菜名与克数手写在相纸下沿留白，热量用橡皮图章盖在角落，
整套界面是暗房（深色墙 + 暖橙安全灯 = 拍照动作），相纸是唯一发光物。
三个工艺细节：相纸三件套比例 + 纸纤维颗粒、抽帧式显影动画、35mm 胶片条周视图。
原创点：新建一餐时菜一格一格「显影」浮现，把拍照录入本身做成显影隐喻。
